Перенос фото, видео и приложений между Android-телефонами по Wi-Fi. Отдельная вкладка «Полный перенос» собирает всё разом: контакты, медиатеку, APK и загрузки — для переезда на новый телефон.

## Как это работает

- Три пути соединения: одна сеть Wi-Fi, точка доступа одного из телефонов или Wi-Fi Direct без роутера.
- Сопряжение тремя путями: QR-код (получатель показывает, отправитель сканирует камеру), UDP-поиск в локальной сети или Wi-Fi Direct.
- QR содержит адрес, порт и одноразовый ключ сессии — канал шифруется сразу и защищён от посредника.
- Поиск по сети и Wi-Fi Direct без QR тоже шифруются: ключи выводятся через ECDH P-256 + HKDF (SHA-256), это защита от прослушки, но не от активного посредника — для полной защиты используйте QR.
- Передача идёт по TCP (порт 47470), всё после рукопожатия зашифровано AES-256-GCM: манифест, файлы по очереди, подтверждение после каждого.
- В Wi-Fi Direct отправитель инициирует подключение, телефон-получатель становится владельцем группы; Android на нём покажет запрос — нужно нажать «Принять».
- Обрыв не теряет прогресс: получатель хранит недописанные файлы как `.fraypart`, при повторной передаче отправитель докачивает с места разрыва.
- Во время передачи приложение держит процессор включённым (wake lock), чтобы телефон не заснул посреди гигабайтов.
- Полученные файлы сохраняются в `Download/Fray`, структура подпапок выбранной папки сохраняется.

## Возможности

- Фото и видео из медиатеки, оригиналы без сжатия.
- Установленные приложения — отправка APK, кроме системных.
- Контакты одним файлом vCard, открывается любым менеджером контактов.
- Файлы из папки загрузок на Android 10 и новее.
- Папки целиком: выберите папку — уйдут все файлы со всех вложенных уровней (пустые папки не переносятся).
- Вкладка «Полный перенос»: одна кнопка на старом телефоне, одна на новом.
- Сопряжение через QR-код одним сканированием.
- Wi-Fi Direct: перенос без общего Wi-Fi, телефоны соединяются напрямую.
- Шифрование канала: AES-256-GCM с одноразовым ключом из QR либо ECDH.
- Докачка после обрыва сети или перезапуска приложения.
- Скорость передачи в прогрессе; повторная передача того же набора файлов переносит только новое.
- История передач с размером и временем.
- Material 3 Expressive: `MaterialExpressiveTheme`, `MotionScheme.expressive()`, крупные радиусы и пружинная анимация.

## Ограничения

- SMS, журнал звонков и системные настройки не переносятся.
- Переносятся APK приложений, но не их данные и не переписки — для этого у Google есть резервное копирование.
- На Android 9 и старше поиск файлов из загрузок недоступен.
- Wi-Fi Direct на телефоне-получателе требует подтверждения системного запроса Android.

## Сборка

Нужен JDK 17.

```bash
./gradlew assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

Тесты:

```bash
./gradlew testDebugUnitTest
```

Релиз-сборка подписывается автоматически, если заданы переменные `FRAY_KEYSTORE`, `FRAY_KEYSTORE_PASSWORD`, `FRAY_KEY_ALIAS`, `FRAY_KEY_PASSWORD` или лежит `keystore.properties` (не в репозитории). CI подписывает release из секретов репозитория: готовый `app-release.apk` — в артефактах Actions. R8/обфускация выключена: включайте только после проверки релиза на устройстве.

## Стек

Kotlin (встроенная поддержка в AGP 9), Jetpack Compose, `androidx.compose.material3:material3:1.5.0`, Kotlin coroutines, AGP 9.5.1, Gradle 9.9.1. Сборка и тесты прогоняются в GitHub Actions на каждый пуш.

## Дорожная карта

- Потоковая упаковка мелких файлов в один поток — скорость на тысячах мелких файлов.
- Передача на ПК без установки софта: страница в браузере.
- Системное меню «Поделиться» и отправка ссылок/буфера обмена.
- Фоновый сервис с уведомлением для передачи.
- Настройка места сохранения.
